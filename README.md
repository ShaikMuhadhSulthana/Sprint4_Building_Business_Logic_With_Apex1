# Placement Management System - Sprint 4
## Building Business Logic with Apex

---

## Project Overview

The Placement Management System is designed to manage students, company job postings, applications, and placement activities.

This sprint focuses on understanding business logic before implementing Apex code.

The objective of this sprint is to analyse business requirements, identify system rules, and design Apex class responsibilities based on different business operations.

---

# Sprint Objective

The main objective of Sprint 4 is:

- Understand business logic in Salesforce
- Convert requirements into business rules
- Identify automatic system decisions
- Design Apex classes based on responsibilities

---

# Work Completed

The following activities were completed in this sprint:

✅ Analysed placement management requirements

✅ Identified business rules for applications

✅ Designed Apex class responsibilities

✅ Planned service-based architecture

✅ Documented future Apex implementation approach

---

# Business Logic Understanding

Business logic defines how the application should behave according to organisational requirements.

Instead of only storing records, the system should make decisions automatically.

Example:

- Check student CGPA before applying
- Verify company eligibility
- Prevent duplicate applications
- Reject applications after deadlines

---

# Apex Class Planning

The following classes were designed:

### StudentService

Responsible for student-related operations.

### JobService

Responsible for company job management.

### ApplicationService

Responsible for handling placement applications.
